# โชคนที 2019 — เว็บไซต์ให้เช่ารถแบ็คโฮ

เว็บไซต์ Next.js สำหรับ Vercel

## เริ่มต้น

```bash
npm install
npm run dev
```

เปิด http://localhost:3000 และใช้ `npm run build` เพื่อตรวจสอบ production build ก่อนนำ repository ไปเชื่อมกับ Vercel

## แก้ไขข้อมูลและรูปรถ

- เนื้อหาและรายการรถอยู่ใน `app/page.tsx` โดยพื้นที่ภาพในแต่ละการ์ดใช้ `.fleet-image` สามารถแทนที่ด้วยรูปที่เก็บใน `public/` ได้
- โลโก้อยู่ที่ `public/logo.png`
- รายการรถและราคาอ้างอิงจากเว็บไซต์ที่ผู้ใช้ระบุ โปรดยืนยันความพร้อมและราคาอีกครั้งก่อนเผยแพร่



## ระบบหลังบ้าน (Neon)

ระบบจัดการอยู่ที่ `/admin` ใช้ Neon Postgres และ Neon Auth รูปภาพระบุพาธใน public/ หรือ HTTPS URL ยังไม่มีการอัปโหลดภาพจากหน้าแอดมิน

1. สร้างบัญชีลูกค้าผ่าน Neon Auth Users โดยให้ลูกค้ากำหนดข้อมูลเข้าสู่ระบบเอง และคัดลอก user ID ของบัญชี
2. ตั้ง `ADMIN_USER_ID` ใน Vercel ให้ตรงกับ user ID หลังบ้านปิดการแก้ไขจนกว่าจะตั้งค่านี้
3. Neon integration จัดการ `DATABASE_URL` และ `NEON_AUTH_BASE_URL` และต้องตั้ง `NEON_AUTH_COOKIE_SECRET` อย่างน้อย 32 ตัวอักษร ห้าม commit ค่าเหล่านี้ลง Git
4. Redeploy และทดสอบเข้าสู่ระบบ บันทึก และแสดงผลด้วยบัญชีผู้ดูแลจริงก่อนส่งมอบ

ตาราง `site_content` สร้างอัตโนมัติ ข้อมูลเนื้อหาเป็นข้อมูลสาธารณะ ห้ามใส่ข้อมูลลับ อีเมลและรหัสผ่านจัดการโดย Neon Auth
